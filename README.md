# Postgraduate Studies in Artificial Intelligence Systems Engineering

This repository documents my learning journey in the postgraduate programme **Artificial Intelligence Systems Engineering** at the **Faculty of Computer Science, AGH University of Krakow**.

The programme focuses on the design, development, deployment, and maintenance of complete software systems that use artificial intelligence. It covers the full lifecycle of an AI solution: from understanding a problem and preparing data, through selecting and implementing suitable methods, to integrating, deploying, and monitoring the resulting system.

## About the Programme

The curriculum combines software engineering principles with a broad range of artificial intelligence methods and practical system development. It covers both symbolic AI and statistical machine learning, including neural networks, natural language processing, large language models, and computer vision.

A significant part of the programme is devoted to data engineering and MLOps. These areas address the practical challenges of building reliable AI solutions, such as preparing data pipelines, versioning code and datasets, tracking experiments, debugging models, and monitoring systems in production.

The programme also introduces modern computing environments, including cloud services, high-performance computing platforms, clusters, and embedded systems. Alongside technical topics, it addresses legal aspects of AI, including relevant regulations, copyright, and the use of AI tools.

## Topics Covered

- **Software engineering:** Python programming, AI and machine learning libraries, version control with Git, teamwork, and web technologies.
- **AI methods:** symbolic AI, knowledge representation and reasoning, heuristic optimisation, classical machine learning, and neural networks.
- **Natural language processing:** techniques ranging from classical NLP to large language models.
- **Computer vision:** image processing and analysis.
- **Data engineering:** data formats, data pipelines, and vector databases.
- **MLOps:** code and data versioning, experiment tracking, model debugging, deployment, and production monitoring, including data and concept drift.
- **Computing environments:** cloud services, networked systems, supercomputers, computing clusters, microplatforms, and embedded systems.
- **Legal aspects of AI:** regulations, copyright, and the responsible use of AI tools.
- **AI-assisted engineering:** using AI assistants and agents to support development while carefully reviewing and verifying the resulting work.
